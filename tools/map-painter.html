Changing the grid re-samples the existing painting onto the new grid (nearest cell), so nothing is lost — but a coarser grid will blur fine edges. Painting autosaves in this browser per image; use Save JSON for a copy you can move between machines.
Pick a colour, then paint on the map — one finger/click paints, the +/- buttons zoom, two-finger drag or middle/right-mouse drag pans while zoomed.
